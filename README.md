区块链核心常用工具集（10个高频调用模块）

项目名称
`Blockchain-Core-Common-Tools`

项目介绍
本项目是一套区块链开发必备的 高频核心工具集，基于C++开发（轻量化、低耦合、无依赖冲突），包含10个最常用、最易调用的基础模块，覆盖哈希计算、钱包生成、日志输出、配置加载、交易组装等公链开发高频场景。所有模块可独立调用、快速集成，无需额外修改，适配各类区块链公链/联盟链项目，大幅提升开发效率，降低基础工具开发成本。
核心优势：轻量化、无冗余代码、接口简洁、易调用、可单独引入任一模块，完美适配C++为主的区块链项目，兼容多平台编译部署。


核心特性
- 哈希工具：快速计算区块哈希、地址哈希，适配区块链数据校验场景
- 钱包生成：一键生成钱包地址、公钥种子，无需复杂加密逻辑
- 日志输出：分级日志（INFO/ERROR/CHAIN），带时间戳+模块标识，便于调试
- 配置加载：灵活读取项目参数、端口配置，支持默认值兜底
- 交易组装：快速构造原始交易数据，序列化格式适配链上传输
- 文件操作：本地文件读写、追加，适配配置文件、日志落地需求
- 时间工具：时间戳、时间格式化、过期判断，适配区块时间、交易时间场景
- 大数计算：安全加减乘，防溢出，适配资产金额、区块高度计算
- JSON解析：轻量键值解析，适配RPC接口数据交互、配置文件读取
- 网络请求：基础HTTP GET请求，适配链外节点数据拉取、跨节点交互


文件清单 & 功能说明（10个核心模块）
1. Chain_Hash_Util.hpp — 通用哈希工具类，提供简单哈希计算、区块哈希生成、钱包地址哈希截取功能，接口简洁，直接调用静态方法即可完成哈希计算。
2. Basic_Json_Parser.cpp — 轻量级JSON键值解析工具，无需依赖第三方JSON库，可快速解析RPC交互、配置文件中的JSON数据，支持字符串、整数类型取值。
3. Wallet_Address_Creator.cpp — 钱包地址生成工具，支持通过公钥种子生成链内钱包地址，可随机生成公钥种子，一键生成新钱包，适配账户创建场景。
4. Time_Tool_Common.hpp — 时间工具类，提供当前时间戳获取、时间戳格式化（YYYY-MM-DD HH:MM:SS）、时间过期判断功能，适配区块时间、交易有效期校验。
5. Simple_File_Operate.cpp — 本地文件操作工具，支持文件写入、读取、追加，适配配置文件保存、日志落地、区块数据临时存储等场景，无需复杂文件操作逻辑。
6. Tx_Data_Builder.hpp — 交易数据组装工具，提供原始交易结构体定义、交易数据序列化功能，可快速构造转账交易数据，直接用于交易池提交、链上传输。
7. Net_Url_Request.cpp — 基础网络请求工具，基于curl实现HTTP GET请求，可用于拉取链外节点状态、获取第三方数据，适配跨节点数据交互场景。
8. Num_Safe_Calc.hpp — 大数安全计算工具，提供无溢出的加减乘运算，返回运算结果是否有效，适配资产金额、区块高度、手续费等敏感数值计算。
9. Log_Output_Common.cpp — 全局日志输出工具，支持INFO（普通信息）、ERROR（错误信息）、CHAIN（链相关信息）三级日志，带时间戳和模块标识，便于开发调试、问题定位。
10. Config_Params_Load.hpp — 配置参数加载工具，支持配置键值对存储、字符串/整数/端口类型参数读取，支持默认值兜底，适配项目端口、节点参数、共识参数等配置管理。


使用说明
1.  环境要求：支持Linux、macOS、Windows多平台，基于C++17编译，无需额外依赖第三方库（Net_Url_Request.cpp需依赖curl库，可按需编译）。
2.  集成方式：将所需文件直接放入项目目录，包含对应头文件（.hpp）即可调用，所有模块独立解耦，可单独引入，无需修改核心逻辑。
3.  调用示例：如生成新钱包，直接调用 WalletAddressCreator::generate_new_wallet() 即可返回新的钱包地址；计算区块哈希，调用 ChainHashUtil::calc_block_hash(高度, 前块哈希, nonce) 即可快速获取。
